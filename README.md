## معرفی

**Over-Tun v5.0 Stealth Pro+** یک راهکار مهندسی‌شده برای ایجاد تانل معکوس امن، سریع و پایدار بین سرورهای ایران و خارج است که ترافیک کاربران را بدون افت سرعت و با بیشترین مقاومت در برابر **DPI** و **Active Probing** به سرور مقصد (مثل Xray / 3x-ui) منتقل می‌کند.

برخلاف تانل‌های FRP معمولی که به دلیل باز نگه داشتن ده‌ها سوکت هم‌زمان، استفاده از گواهی خودامضا و نداشتن وب‌سایت واقعی در برابر اسکن فعال به‌سرعت شناسایی می‌شوند، در **Over-Tun v5.0** هسته‌ی تانل کاملاً پشت **Double-Nginx TLS 1.3**، **گواهی واقعی Let's Encrypt** و **مالتی‌پلکسینگ Yamux** (با الگوی ترافیکی مرورگر) پنهان شده است و همه‌چیز با یک دستور و از طریق **پنل وب شیشه‌ای** مدیریت می‌شود.

> [!NOTE]
> این ابزار برای اتصال سرورهای شخصی شما به یکدیگر طراحی شده است. سرور ایران محل اتصال کاربران و سرور خارج مقصد ترافیک است.

## تغییرات نسخه 5.0

- **معماری ضد پروب Stealth Pro+ (Double-Nginx TLS 1.3):** قرار گرفتن Nginx در هر دو سمت ایران و خارج برای حذف کامل اثرانگشت TLS کلاینت Go/FRP و شبیه‌سازی کامل ترافیک وب واقعی.
- **گواهی معتبر Let's Encrypt + سایت پوششی واقعی (Decoy):** صدور و تمدید خودکار SSL معتبر همراه با یک وب‌سایت چندصفحه‌ای واقعی (یا سایت Reverse Proxy دلخواه شما) روی پورت `443`.
- **حذف کامل امضای `/~!frp`:** مسیر پیش‌فرض FRP همیشه `404` برمی‌گرداند و برای هر تانل یک مسیر تصادفی اختصاصی همراه با هدر امنیتی ۳۲ کاراکتری (`X-Edge-Key`) و محدودیت نرخ درخواست (`Rate Limit`) ساخته می‌شود.
- **الگوی ترافیکی مرورگر (Yamux):** جایگزینی استخرهای مشکوک ۲۰ تا ۱۵۰ اتصالی با تنها **۲ تا ۶ سوکت مالتی‌پلکس‌شده** (مشابه رفتار مرورگر کروم) بدون کاهش سرعت.
- **قفل IP ضد پروب (Strict IP Lock):** قفل کردن مسیر تانل فقط روی IP سرور(های) خارج شما با یک کلیک؛ هر IP دیگری (حتی اسکنر DPI) خطای عادی `404` دریافت می‌کند.
- **تست زنده امنیت ۵ مرحله‌ای (Self-Audit):** بررسی عملی مقاومت سرور در برابر حملات Active Probing و ارائه گزارش نمره امنیت تا گرید `A+`.
- **موتور Hyper-Speed:** حذف رمزنگاری مضاعف (Zero Double-TLS)، فعال‌سازی خودکار **TCP MSS Clamping** و `MTU Probing` (رفع فریز و افت سرعت روی اپراتورهای ایران)، `TLS Session Reuse`، تیونینگ `BBR + FQ + Autocork=0`، پخش بار روی هسته‌ها (`RPS/XPS`) و مدیریت هوشمند حافظه (`GOGC` + `GOMEMLIMIT`).

## قابلیت‌ها

- **مقاومت حداکثری در برابر Active Probing و DPI** — پاسخ‌دهی وب‌سایت واقعی روی پورت `443` با گواهی معتبر Let's Encrypt و حذف کامل گواهی خودامضا و SNI جعلی.
- **چند تانل روی یک سرور (تا ۲۰ تانل)** — پشتیبانی از چندین تانل مستقل با نام و پورت‌های اینباند جداگانه؛ در حالت `Stealth Pro+` حتی چندین تانل با ساب‌دامین‌های مختلف می‌توانند مشترکاً روی یک پورت `443` اجرا شوند.
- **سیستم ضد اکسس (Multi-Kharej Failover)** — همان کد اتصال سرور ایران را روی ۲ یا چند سرور خارج وارد کنید؛ ترافیک بین آن‌ها تقسیم می‌شود و اگر IP یکی مسدود یا قطع شد، بقیه خودکار و بدون تغییر کانفیگ کاربران ادامه می‌دهند.
- **سه حالت سرعت هوشمند** — `Medium` (۲ سوکت، سبک)، `Turbo` (۴ سوکت، پیشنهادی) و `Advanced` (۶ سوکت، حداکثر سرعت با RPS/XPS و busy-poll).
- **حذف بایت امضای FRP در TLS مستقیم** — فعال بودن `disableCustomTLSFirstByte` در متد TLS مستقیم برای استانداردسازی کامل هندشیک.
- **سرویس خودترمیم Watchdog Pro** — پایش دائمی `frpc` و `nginx` روی سرور خارج و بازیابی خودکار در صورت اختلال؛ به همراه سوئیچ خودکار در حالت‌های مستقیم TLS/WSS.
- **پنل وب مانیتورینگ (طراحی شیشه‌ای Black / White Gold)** — نمودار ترافیک زنده، CPU/RAM، پینگ، مدت اتصال، کاربران فعال (IP یکتا)، کنترل IP Lock و اجرای زنده تست امنیت.
- **آمار مصرف دقیق بایت‌به‌بایت** — مصرف هر پورت اینباند مستقیماً از API سرور FRP خوانده می‌شود (دقیقاً مطابق با آمار x-ui).
- **منوی ترمینال و CLI کامل** — مدیریت سریع با دستور `over-tun` یا دستورات غیرتعاملی در اسکریپت‌ها.

## نصب

روی **هر دو سرور** (ایران و خارج) این دستور را اجرا کنید:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/ibooplay/Overal-Tun/main/tunnel.sh)
```

بعد از نصب، هر زمان با دستور زیر منو باز می‌شود:

```bash
over-tun
```

### مراحل راه‌اندازی (حالت پیشنهادی Stealth Pro+)

۱. یک دامنه یا ساب‌دامین (مثلاً `cdn.yourdomain.com`) را با رکورد `A` به IP **سرور ایران** متصل کنید و مطمئن شوید پورت‌های `80` و `443` روی سرور ایران باز هستند.
۲. روی **سرور ایران** گزینه‌ی `۱` را بزنید، متد `STEALTH Pro+` را انتخاب کرده و نام، دامنه و پورت‌های اینباند را وارد کنید. گواهی **Let's Encrypt** و سایت پوششی به‌صورت خودکار ساخته می‌شوند و در پایان یک **کد اتصال** دریافت می‌کنید.
۳. روی **سرور خارج** گزینه‌ی `۲` را بزنید، IP سرور ایران و همان کد اتصال را وارد کنید (سرویس Nginx سمت خارج فقط روی `127.0.0.1` تنظیم می‌شود و هیچ تداخلی با پورت‌های 80/443 یا پنل x-ui شما ندارد).
۴. *(توصیه‌شده)* پس از برقراری اتصال، روی **سرور ایران** قفل IP و تست امنیت را اجرا کنید:

```bash
over-tun iplock auto
over-tun audit
```

### آپدیت

```bash
over-tun update
```

یا برای ارتقای کانفیگ تانل‌های قدیمی و بروزرسانی پنل وب:

```bash
over-tun migrate
over-tun panel-refresh
```

## پنل وب

برای نصب پنل، در منو گزینه‌ی **«۱۳ — Install / reset panel»** را بزنید. آدرس پنل، نام کاربری و رمز عبور به شما داده می‌شود.

| بخش | توضیح |
|------|-------|
| **داشبورد** | وضعیت لحظه‌ای، ترافیک زنده تانل، CPU/RAM، پینگ، مدت اتصال و فهرست تانل‌ها |
| **مصرف پورت‌ها** | آمار دقیق دانلود/آپلود هر پورت اینباند (امروز / ۷ روز / ۱۴ روز / کل) و تعداد IP یکتا |
| **تانل** | ساخت، ویرایش، تغییر نام، افزودن/حذف پورت، **قفل IP ضد پروب** و **تست زنده امنیت** |
| **لاگ‌ها** | لاگ زنده تانل با فیلتر خطا/هشدار، رویدادهای اتصال و گزارش فعالیت‌های پنل |
| **تنظیمات** | تم طلایی مشکی / طلایی سفید، تغییر رمز پنل و آپدیت با یک کلیک |

امنیت پنل: هش رمز عبور با **PBKDF2-SHA256** (۲۰۰٬۰۰۰ دور)، نشست کوکی `HttpOnly / SameSite=Strict` و قفل ورود پس از ۵ تلاش ناموفق.

## روش‌های تانل

| روش | توضیح | وضعیت |
|------|-------|--------|
| **STEALTH Pro+** | Double-Nginx TLS 1.3 + گواهی Let's Encrypt + سایت پوششی واقعی + مسیر و هدر مخفی + Yamux | **پیشنهادی (ضد DPI)** |
| **TLS** | TCP + TLS استاندارد (حذف بایت `0x17`) + Yamux + پشتیبانی از Let's Encrypt | سریع و مستقیم |
| **WSS** | WebSocket + TLS مستقیم + Yamux | جایگزین TLS مستقیم |
| **QUIC** | روی UDP + Yamux، مناسب خطوط پرنوسان | نیازمند باز بودن UDP |
| **KCP** | روی UDP برای خطوط با پکت‌لاس شدید | ~۱۵٪ ترافیک بیشتر |

> در حالت‌های مستقیم، TLS و WSS را می‌توان از پنل وب بدون نصب مجدد جابه‌جا کرد.

## دستورات کاربردی

```bash
over-tun                        # باز کردن منوی تعاملی
over-tun list                   # لیست تانل‌ها و وضعیت سرویس‌ها
over-tun audit                  # اجرای تست ۵ مرحله‌ای امنیت و ضد Active Probing (سرور ایران)
over-tun iplock auto            # قفل مسیر تانل روی IP سرورهای خارج متصل (سرور ایران)
over-tun iplock set 1.2.3.4     # ثبت دستی IP مجاز در قفل ضد پروب
over-tun iplock off             # باز کردن قفل IP
over-tun mode turbo             # تغییر حالت سرعت (medium / turbo / advanced)
over-tun port-add 2053          # افزودن پورت اینباند جدید
over-tun port-del 2053          # حذف پورت اینباند
over-tun update                 # آپدیت اسکریپت و پنل وب
```

## سوالات متداول

**فرق Over-Tun v5.0 با تانل FRP معمولی چیست؟**
در FRP معمولی باز نگه داشتن ده‌ها سوکت هم‌زمان، گواهی خودامضا، مسیر شناخته‌شده‌ی `/~!frp` و نبود سایت پوششی باعث شناسایی سریع سرور می‌شود. در **Over-Tun v5.0** از معماری **Double-Nginx TLS 1.3**، گواهی معتبر **Let's Encrypt**، وب‌سایت واقعی Fallback، مسیر و کلید مخفی، **قفل IP** و تنها ۲ تا ۶ سوکت مالتی‌پلکس‌شده (Yamux) استفاده می‌شود.

**آیا نصب Stealth Pro+ روی سرور خارج با پنل x-ui یا پورت 443 تداخل دارد؟**
خیر. Nginx سمت خارج فقط روی `127.0.0.1` (پورت داخلی `17400+`) گوش می‌دهد و هیچ پورت عمومی (80 یا 443) را روی سرور خارج اشغال نمی‌کند.

**چند سرور خارج پشت یک تانل می‌شود گذاشت؟**
بله. همان کد اتصال سرور ایران را روی ۲ یا چند سرور خارج وارد کنید؛ ترافیک بین آن‌ها تقسیم می‌شود و اگر یکی اکسس شود، بقیه خودکار سرویس‌دهی را ادامه می‌دهند. (در صورت فعال کردن `IP Lock`، پس از اضافه کردن سرور خارج جدید دوباره `over-tun iplock auto` را بزنید.)

**مصرف ترافیک دو برابر حساب می‌شود؟**
خیر. آمار پنل از ترافیک واقعی کاربران روی هر پورت خوانده می‌شود. فقط توجه کنید چون سرور ایران واسطه است، برخی دیتاسنترها ترافیک ورودی و خروجی سرور را جداگانه محاسبه می‌کنند.

**در زمان قطعی کامل اینترنت بین‌الملل کار می‌کند؟**
خیر. هیچ تانلی در قطعی کامل بین‌الملل کار نمی‌کند؛ تانل فقط از مسیرهای باز برای انتقال امن و پایدار ترافیک استفاده می‌کند.
