## معرفی

**Over-Tun** یک نصب‌کننده‌ی تانل معکوس بین سرور ایران و سرور خارج است که ترافیک کاربران را به‌صورت رمزنگاری‌شده و پایدار از سرور ایران به سرور خارج می‌رساند. مناسب برای وصل کردن پنل‌های x-ui / Xray روی سرور خارج به کاربران داخل، بدون قطعی و نوسان.

تانل روی موتور **FRP** با یک استخر بزرگ از اتصال‌های از پیش باز اجرا می‌شود، تا هیچ کاربری منتظر باز شدن اتصال جدید نماند. همه‌چیز با یک دستور نصب و از طریق یک **پنل وب زیبا** مدیریت می‌شود.

> [!NOTE]
> این ابزار برای وصل کردن سرورهای شخصی شما به یکدیگر است. سرور ایران محل اتصال کاربران و سرور خارج مقصد ترافیک است.

---

## قابلیت‌ها

- **موتور FRP با استخر اتصال** — اتصال‌های از پیش باز بین دو سرور، بدون نوسان و بدون تأخیرِ باز شدن اتصال جدید.
- **چند تانل روی یک سرور** — یک سرور ایران می‌تواند هم‌زمان چند تانل به چند سرور خارج داشته باشد؛ هر کدام با نام، پورت و پورت‌های اینباند جداگانه.
- **سیستم ضد اکسس (پخش بار)** — یک کد اتصال را روی چند سرور خارج وارد کنید؛ ترافیک بین آن‌ها پخش می‌شود و اگر IP یکی مسدود شد، بقیه خودکار ادامه می‌دهند.
- **سوئیچ خودکار روش** — اگر یک روش حدود ۳ دقیقه وصل نشود، تانل خودکار بین TLS و WSS جابه‌جا می‌شود.
- **سه حالت سرعت** — Medium (سبک)، Turbo (پیشنهادی)، Advanced (حداکثر سرعت) با تنظیم خودکار کرنل، BBR و کارت شبکه.
- **پنل وب مانیتورینگ** — نمودار ترافیک زنده، CPU/RAM، پینگ، مدت اتصال، کاربران فعال و آمار مصرف دقیق هر پورت.
- **آمار مصرف بایت‌به‌بایت** — مصرف هر پورت اینباند از API خود FRP خوانده می‌شود؛ دقیقاً همان عددی که x-ui نشان می‌دهد.
- **سه زبانه** — فارسی، English، العربية؛ با تم طلایی مشکی و طلایی سفید.
- **واچ‌داگ** — اتصال سرور خارج دائم بررسی و در صورت قطعی خودکار برقرار می‌شود.
- **منوی ترمینال دسته‌بندی‌شده** — با دستور `over-tun` باز می‌شود و بعد از هر کار باز می‌ماند.

## نصب

روی **هر دو سرور** (ایران و خارج) این دستور را اجرا کنید:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/ibooplay/Overal-Tun/main/tunnel.sh)
```

بعد از نصب، هر زمان با یکی از این دستورها منو باز می‌شود:

```bash
over-tun
```

### مراحل راه‌اندازی

۱. روی **سرور ایران** گزینه‌ی `۱` را بزنید و یک تانل بسازید (نام، روش، پورت و پورت‌های اینباند). در پایان یک **کد اتصال** می‌گیرید.
۲. روی **سرور خارج** گزینه‌ی `۲` را بزنید، IP سرور ایران و همان کد اتصال را وارد کنید.
۳. تمام. کاربران به IP سرور ایران و پورت‌های اینباند وصل می‌شوند.

### آپدیت

```bash
over-tun update
```

تانل‌های موجود بدون قطعی آپدیت و بهینه می‌شوند.

## پنل وب

برای نصب پنل، در منو گزینه‌ی **«نصب / ریست پنل»** را بزنید. آدرس پنل، نام کاربری و رمز به شما داده می‌شود.

| بخش | توضیح |
|------|-------|
| **داشبورد** | وضعیت لحظه‌ای، ترافیک زنده تانل، CPU/RAM، پینگ و فهرست تانل‌ها |
| **مصرف پورت‌ها** | آمار دقیق دانلود/آپلود هر پورت اینباند، امروز / ۷ روز / کل |
| **تانل** | ساخت، ویرایش، تغییر نام، افزودن/حذف پورت و حذف تانل |
| **لاگ‌ها** | لاگ تانل، رویدادهای اتصال و فعالیت پنل |
| **تنظیمات** | زبان، تم و تغییر رمز پنل |

امنیت پنل: رمز با هش PBKDF2، نشست کوکی‌ای و قفل ورود پس از ۵ تلاش ناموفق.

## روش‌های تانل

| روش | توضیح | چه زمانی |
|------|-------|----------|
| **TLS** | TCP + TLS، رمزنگاری کامل، سریع‌ترین | **پیشنهادی** |
| **WSS** | WebSocket + TLS، شبیه HTTPS معمولی | اگر TLS اختلال داشت |
| **QUIC** | روی UDP، مناسب خطوط پرنوسان | UDP باید باز باشد |
| **KCP** | برای خطوط خیلی بد با پکت‌لاس بالا | ~۱۵٪ ترافیک بیشتر |

> TLS و WSS را می‌توان از پنل وب بدون نصب مجدد جابه‌جا کرد.

## سوالات متداول

**مصرف ترافیک دو برابر حساب می‌شود؟**
خیر. آمار از مصرف واقعی هر پورت خوانده می‌شود. فقط دقت کنید چون سرور ایران واسطه است، بعضی شرکت‌های میزبان ممکن است ورود و خروج را جدا حساب کنند.

**چند سرور خارج پشت یک تانل می‌شود گذاشت؟**
بله. همان کد اتصال را روی چند سرور خارج وارد کنید؛ ترافیک بین‌شان پخش می‌شود.

**در زمان قطعی کامل اینترنت بین‌الملل کار می‌کند؟**
خیر. هیچ تانلی در قطعی کامل کار نمی‌کند؛ تانل فقط از مسیری که باز باشد ترافیک رد می‌کند.
